## Simplify your path to AI production and business impact

Claude is now generally available in Microsoft Foundry. Build production applications and enterprise agents with Claude using the Azure authentication, billing, and governance you already have. Usage appears on your Azure invoice and, for customers with a Microsoft Azure commitment, counts toward your MACC. New with general availability, inference can run on Azure infrastructure in a US data zone, operated by Anthropic.

### Frontier intelligence

Build apps and enterprise agents powered by the world's leading models for coding, agents, and office tasks.

### Familiar workflows

Deploy Claude through Azure tools and workflows you already use, with Python, TypeScript, and C# SDKs and more.

### Unified procurement

Claude models in Microsoft Foundry are eligible for Microsoft Azure Consumption Commitment (MACC).

### Consolidated billing

Claude usage appears on your Azure invoice alongside other services, simplifying expense management.
