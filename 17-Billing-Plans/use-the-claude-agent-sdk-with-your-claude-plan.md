# Use the Claude Agent SDK with your Claude plan


**Update October 7, 2026:** Claude Max, Ultra, and Team plans now include **[monthly API credits](monthly-api-credits-for-max-ultra-and-team-plans-claude-help-center.md)**. They cover the Claude API, Claude Managed Agents, and the Claude Agent SDK and `claude -p` when you run them with an API key from your linked Claude Console organization. Nothing changes for your plan: when you’re signed in with your Claude plan, the Claude Agent SDK and `claude -p` still draw from your subscription limits.

**Update June 15, 2026:** We’ve paused the previously-announced changes to Claude Agent SDK usage. For now, nothing has changed: Claude Agent SDK, `claude -p`, and third-party app usage still draw from your subscription limits.
